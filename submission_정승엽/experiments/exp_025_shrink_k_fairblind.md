# exp_025 — TRACKMAN_SHRINK_K 재튜닝 (fair-blind 조건, 기각)

## 실험 개요 (시작 전에 작성)

- **실험 ID**: exp_025
- **날짜 / 담당자**: 2026-08-21 / (Claude)
- **가설**: exp_024에서 기존 trackman 로컬 검증이 낙관적으로 측정돼
  왔음(2024 검증 행이 실제 제출 조건과 달리 실제 2024 시즌내 트랙맨
  데이터의 혜택을 봄)이 드러남 — exp_021의 `TRACKMAN_SHRINK_K=50`
  튜닝도 그 낙관 조건에서 이뤄졌으므로, 실제 제출 조건을 그대로
  재현하는 fair-blind 조건에서 다시 튜닝하면 다른 최적값이 나올 수
  있다.
- **기준(baseline)**: k=50 (production 값), fair-blind 조건에서
  score=735.65(exp_024의 변형 A와 동일 수치).
- **이번에 바꾸는 것**: `TRACKMAN_SHRINK_K` ∈ {20, 35, 50, 75, 100,
  150, 250, 400}만 순차 변경 (exp_009/021과 동일한 coordinate-wise
  스타일). 그 외 전부 고정, 단일 seed=42.
- **검증 방법**: exp_024의 `build_flat_blind_tables`(season<2024
  트랙맨만 사용) 그대로 재사용 — 2024 검증 행이 실제 2025 제출과
  동일하게 sentinel로만 resolve되는 조건.
- **누수 위험 검토**: exp_024와 동일 — season<target_season만 사용,
  leak-safe.

**결론: 기각(변경 불필요).** fair-blind 조건에서도 k=50이 그대로
최선 — exp_021이 optimistic 조건에서 내린 결론이 corrected 조건에서도
그대로 유지됨을 확인. k=75만 노이즈 수준(-0.16, exp_016/021 기준
<2점)으로 근접했을 뿐, 나머지는 전부 뚜렷하게 열세. **production
`TRACKMAN_SHRINK_K=50`은 변경하지 않음, 재학습/아카이브 없음.**

**의의**: exp_024가 제기한 "트랙맨 관련 과거 로컬 튜닝이 낙관 조건에서
이뤄져 실제 제출 조건과 다를 수 있다"는 우려를 이 축(shrink-k)에
한해서는 완전히 해소함 — production 설정이 실제 조건에서도 여전히
최적임이 재확인됨.

**다음 가설**: 이 세션에서 시도 가능한 저비용 축(exp_009 HPO, exp_021
shrink-k ×2, exp_024 trackman 추세외삽, exp_025 shrink-k fair-blind
재검증)을 모두 소진. 남은 유일한 미검증 고가치 후보는 exp_023(라벨
base rate 추세외삽) 리더보드 제출 결과 확인 — 사용자 제출 대기 중.
