# exp_032 — 블렌드 성분별 affine 보정 (exp_037로 병합)

## 실험 개요 (시작 전에 작성)

- **실험 ID**: exp_032
- **날짜 / 담당자**: 2026-08-22 / (Claude, 사용자 요청)
- **가설**: 각 앙상블 멤버(CatBoost-A/B, ExtraTrees)의 raw 확률에
  `p_adj = clip(0.5 + scale·(p-0.5) + shift, 0, 1)` 선형 보정을
  블렌딩 전에 적용하면(팀원 방식) 각 멤버 자체의 미보정을 먼저
  없애고 블렌드해서 추가 이득이 있다.
- **기준(baseline)**: exp_031의 블렌드(raw 836.02, 근사보정 890.18).

## 실행 방식 변경(시간 제약에 따른 결정)

exp_031의 3개 모델 재학습에 약 31분이 걸렸다(`experiments/exp031_run_log.txt`).
affine 보정 자체는 이미 계산된 예측값 위에서 하는 저비용 연산이지만,
exp_031 실행 시 모델/예측값을 캐싱해두지 않아서 이걸 **독립적으로**
검증하려면 3개 모델을 처음부터 다시 학습해야 한다(또 ~31분).

affine 보정은 이종 앙상블(exp_031)처럼 구조 자체를 바꾸는 큰 변경이
아니라 이미 검증된 구조 위에 얹는 저위험 미세조정이므로, **별도
격리 재학습으로 30분을 더 쓰는 대신 exp_037 최종 조립 시 그 자리에서
같이 피팅**하기로 결정(사용자가 시간 제약 하에서 exp_032~035를
진행하되 exp_036은 보류하기로 한 것과 같은 맥락의 우선순위 판단).
