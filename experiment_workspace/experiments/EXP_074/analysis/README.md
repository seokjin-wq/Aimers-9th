# Trackman 익명 투수 연결 진단

- 연결표 생성 데이터: 공식 `train.csv` 2019~2023과 공식 `trackman_history.csv` 2019~2023만 사용
- 평가/검증 행 집계: 사용하지 않음
- 시즌별 최근접 연결의 반복 투수 일관성: 100% 일치 3.10%, 80% 이상 3.34%
- 2019~2022 전역 연결을 2023에 검증한 결과: 팀 일치 59.55%, 투구수 로그 오차 중앙값 0.7852
- 2019~2022 연결과 2019~2023 연결의 안정성: 62.79%

결론: 익명 선수 연결 신뢰도가 부족하므로 선수별 Trackman 연결 피처는 사용하지 않는다. 대신 공식 과거 Trackman만으로 만든 손 유형×카운트 상황 집계가 k=50 기준선에 추가 가치를 주는지만 정식 검증한다.

상세 수치는 `summary.json`, 연결 후보는 CSV 산출물에 보존한다.
