| **column** | **expected_range** | **n_out_of_range** | **out_of_range_values** |
| --- | --- | --- | --- |
| `balls_before` | [0, 3] | 0 | [] |
| `strikes_before` | [0, 2] | 0 | [] |
| `outs_before` | [0, 2] | 0 | [] |

특히 담당2 변수는 **서로 수학적으로 완전히 종속된 컬럼이 여러 개** 있다.

전 행(n=1,475,092)에 대해 세 관계 모두 **100.000% 일치**:

| **relationship** | **matches** | **mismatches** | **match_rate** |
| --- | --- | --- | --- |
| run_total_before == run_top_before + run_bot_before | 1475092 | 0 | 1.0 |
| score_diff_home == run_bot_before - run_top_before | 1475092 | 0 | 1.0 |
| score_diff_pitcher_team == (top_bottom=='T' ? score_diff_home : -score_diff_home) | 1475092 | 0 | 1.0 |
| score_diff_pitcher_team == (top_bottom=='T' ? -score_diff_home : score_diff_home) | 377192 | 1097900 | 0.2557074406206528 |

```
run_total_before
=
run_top_before + run_bot_before
```

가 **1,475,092행 전체에서 100% 성립**

```
score_diff_home
=
run_bot_before (홈팀) - run_top_before (원정)
```

도 **전 행에서 100% 성립**

반대 부호 가설(`top_bottom=='T' ? -score_diff_home : score_diff_home`)은 25.571%만 일치해 기각 — `top_bottom=='T'`(초, 원정팀 공격 = 홈팀 투구)일 때 `score_diff_pitcher_team == score_diff_home`가 정확한 관계임을 데이터로 확인했다 
(야구 규칙과도 일치: 초에는 홈팀이 수비/투구).

**결론**: `run_total_before`, `score_diff_home`, `score_diff_pitcher_team` 3개 컬럼은 `run_top_before`, `run_bot_before`, `top_bottom` 3개로부터 결정론적으로 100% 재구성 가능 — 수학적으로 중복

흥미로운 점: 카운트만 봤을 땐 3-2(풀카운트)가 가장 낮았지만, `outs_before`까지 함께 보면 **"3볼 + 무사(0아웃)" 조합이 strikes 값과 무관하게 가장 낮다** (3-1-0, 3-0-0, 3-2-0이 상위 3개 최저 조합을 모두 차지, outs=1·2에서는 3볼 페널티가 훨씬 완화됨 — 예: 3-1-1은 -1.90%p, 3-1-2는 -0.56%p). 

즉 `outs_before`는 단독 신호는 약하지만 카운트와 상호작용할 때는 신호가 커짐.

# 8. 점수 자체와 제구 성공률

`run_total_before`를 보면:

| 양팀 총점 | 제구 성공률 |
| --- | --- |
| 0 | 53.27% |
| 1 | 52.76% |
| 2 | 52.60% |
| 3 | 52.57% |
| 4 | 52.91% |
| 5 | 52.47% |
| 6 | 52.07% |
| 7~8 | 51.58% |
| 9~10 | 51.61% |
| 11+ | 51.40% |

대체로:

> 경기 총점이 높아질수록 제구 성공률이 낮아지는 경향이 보인다
> 

하지만 여기서 바로 “득점이 많아지면 제구력이 나빠진다”라고 하는 건 무리

왜냐하면 `run_total_before`는 **경기 진행 정도와 강하게 연관될 가능성**이 있기 때문.

예:

```
총점 0
→ 경기 초반일 가능성 높음

총점 10+
→ 경기 후반 또는 난타전일 가능성 높음
```

- 이닝
- 경기 유형
- 투수 교체
- 시즌
- 주자 상황

등이 같이 영향을 줬을 수 있다는 것이다. 점수차가 높을수록 제구 성공확률이 떨어지는 것도 맞지만, 여기에 더해서 이닝, 시즌, 경기 유형 등의 변수들도 영향을 줬을 수 있다.

즉 이건 **confounding 가능성이 있는 EDA 결과**.

> “run_total_before가 커질수록 성공률 감소가 관찰되지만, inning 및 게임 진행 상황과의 혼재효과를 통제할 필요가 있다.”
>

```

    ↓
접전 / 동점 ← 높음
    ↓
큰 리드 ← 다시 낮음
```

### **구간화 (단순 기준, 최적화 아님)**

`score_diff_pitcher_team` 기준 5구간 (큰 열세 ≤-4 / 열세 -3~-1 / 동점 0 / 리드 1~3 / 큰 리드 ≥4)

단, `|score_diff| > 15` 구간은 표본이 급감(n<100, 일부 n<5)해서 성공률이 매우 불안정하다 (예: `score_diff_pitcher_team=-26`는 n=2, 성공률 0% — 사실상 노이즈, 해석 금지)

| **구간** | **n** | **성공률** | **전체 대비** |
| --- | --- | --- | --- |
| 큰 열세(≤-4) | 178,321 | 51.04% | -1.33%p |
| 열세(-3~-1) | 359,384 | 52.25% | -0.12%p |
| **동점(0)** | 377,192 | **53.01%** | **+0.63%p (최고)** |
| 리드(1~3) | 373,161 | 52.56% | +0.18%p |
| 큰 리드(≥4) | 187,034 | 52.26% | -0.12%p |

**동점 상황이 성공률이 가장 높고, 큰 열세가 가장 낮다.** 주목할 점은 비대칭성 — 큰 열세(-1.33%p)가 큰 리드(-0.12%p)보다 훨씬 큰 폭으로 성공률을 낮춘다. 열세와 큰 리드는 편차 크기가 거의 같다(-0.12%p대).

# 11. 중요한 중복성 발견

담당 2번 데이터셋 에서 팀에 가져갈 수 있는 가장 명확한 결과 중 하나.

실제 train 데이터 전체에서:

### 관계 1

```
run_total_before = run_top_before + run_bot_before
```

100% 일치.

### 관계 2

```
score_diff_home = run_bot_before - run_top_before
```

100% 일치.

### 관계 3

`top_bottom`을 같이 알면: `score_diff_pitcher_team`도 `score_diff_home`에서 완전히 결정 가능.

투수가 홈팀인 경우(top_bottom = t 인 경우) `score_diff_home = score_diff_pitcher_team`

즉:

```
run_top
run_bot
run_total
score_diff_home
score_diff_pitcher_team
```

은 정보적으로 중복돼 있어 보인다.

이건 다 지워도 된다는 것이 아니라, 오히려 **같은 원 정보를 여러 형태로 표현해놓은 피처** 라는 뜻.

RandomForest나 boosting에서는 이런 파생 표현이 오히려 학습을 쉽게 해줄 수도 있다.

그러므로 EDA 결과는:

> 중복성 있음 → 제거 후보 → ablation test 필요
>

# 12. 더 중요한 발견: 시즌 Drift

이건 담당 2번만 보다가 놓치기 쉬운데, 실제 전체 train 컬럼들을 확인하면서 눈에 띄는 중요한 점을 기록한 것.

| 2021 | 247,088 | 53.28% | +0.90%p |
| 2022 | 247,472 | 52.89% | +0.52%p |
| 2023 | 245,525 | 50.00% | -2.38%p |

| --- | --- |

| 2021 | 53.28% |
| 2022 | 52.89% |

전체 제구 성공률이 2019년 56.47%에서 2024년 48.61%까지 6개 시즌 동안 거의 단조적으로 7.85%p 하락한다. 이는 이번 그룹의 어떤 단일 변수 효과(가장 큰 게 풀카운트 -2.42%p)보다도 훨씬 큰 폭이다

- 굉장히 큰 감소. 시즌을 거듭할 수록 제구 성공확률 감소?
- 2019와 2024 사이가 약 **7.86%p** 나 차이남.

2025를 예측하는 대회이므로:

> 전체 2019~2024를 섞어 본 단순 target rate만으로 상황 효과를 해석하면 
시즌 drift에 의해 왜곡될 수 있다는 의미

# 13. 그래서 Count 효과도 시즌별로 다시 봐야 한다

실제로 3-2 count의 성공률은 다음과 같이 떨어진다.

- 2019: 약 55.67%
- 2020: 50.55%
- 2021: 51.42%
- 2022: 50.17%
- 2023: 46.56%
- 2024: **45.70%**

그런데 전체 target 자체도 같이 내려갔다.

그래서 아래도 같이 보는 게 좋다. 

```
count 성공률 - 해당 시즌 전체 성공률
```

시즌 전체 성공률과 비교해서도 해당 카운트 성공률이 낮은지. 
단순히 시즌을 거듭하면서 낮아진 게 아니라 시즌 효과에 더해 카운트 상황도 효과가 있는지 판단하라는 말

예를 들어 2024:

```
전체 = 48.61%
3-2 = 45.70%

→ 약 -2.91%p
```

즉 3-2가 그냥 2024라서 낮은 게 아니라, **같은 시즌 평균보다도 낮다**는 걸 확인할 수 있다.

이게 훨씬 좋은 EDA.

# **14. 주요 발견 (요약)**

- 시즌 전체 하락 추세(-7.85%p, 2019→2024)가 이번 그룹에서 관측된 가장 큰 신호이며, 어떤 개별 카운트/점수차 효과보다 크다.
- 볼카운트가 늘수록(특히 3볼) 성공률이 낮아지는 패턴이 일관됨; 스트라이크 단독 효과는 약하고 비단조적.
- 풀카운트(3-2)가 카운트 단독 기준으로는 최저지만, outs까지 보면 "3볼+무사(0아웃)" 조합이 strikes 값과 무관하게 더 낮음 — outs와 count의 상호작용 신호가 outs 단독보다 강함.
- 큰 점수차 열세가 큰 점수차 리드보다 제구에 더 크게(비대칭적으로) 악영향 — 열세 압박이 리드 여유보다 효과가 큼.
- `run_total_before`/`score_diff_home`/`score_diff_pitcher_team`은 수학적으로 100% 중복(재구성 가능).
- 8개 컬럼 각각의 marginal 효과는 대체로 ±2%p 이내로 작아, 단독보다 `asof_*` 투수 이력 계열과의 상호작용에서 더 큰 힘을 발휘할 가능성.

## **17. 팀 회의용 핵심 결론**

1. **관찰**: 전체 제구 성공률이 2019→2024 사이 꾸준히 하락한다. 
    1. **근거**: 2019 56.47% → 2020 53.27% → 2021 53.28% → 2022 52.89% → 2023 50.00% → 2024 48.61% (전체 평균 52.38%).
