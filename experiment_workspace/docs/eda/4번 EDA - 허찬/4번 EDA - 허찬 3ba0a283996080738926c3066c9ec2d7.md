## 2. 품질 검사와 구조적 불변식

단순 결측률뿐 아니라, “정의상 맞아야 하는 성질”을 검사했습니다.

### 핵심 결과

| 검사 | 결과 | 해석 |
| --- | --- | --- |
| rate가 0~1 밖인가 | 0건 | 범위 OK |
| ball + strike ≈ 1? | 평균 절대오차 ≈ **0.19** | 합이 1이 **아님** → 상호배타 아님 |
| 구종 3개 합 ≈ 1? | 오차 ≈ 0 | 사실상 합=1 (composition) |
| `n` == `pitchmix_n`? | **100%** | 완전 중복 컬럼 |
| 투수별 `n` 감소 행 | 0건 | 누적 정의 OK |
| 결측 | 792행 | 전부 `n=0` cold-start |

### Insight A. 결측은 버그가 아니라 cold-start

- rate 결측 792행 = `asof_pitcher_n = 0` 792행과 일치
- `n > 0`인데 결측인 경우 **0건**
- 투수 792명과 같아서, **투수별 첫 관측(이력 없음)** 으로 해석

**모델링 함의**

- 평균으로만 때우지 말고 `n` / `log1p(n)` / missing indicator를 같이 고려

### Insight B. ball·strike는 `1 - 나머지`로 대체하면 안 됨

- 표 설명도 “볼성/스트라이크성 결과”라 전체가 둘로만 안 나뉨
- 평균적으로 약 20%는 둘 다 아닌 결과

### Insight C. 구종 3개와 두 표본 수

- fastball + breaking + offspeed ≈ 1 → 구성비 피처
- `asof_pitcher_n`과 `asof_pitcher_pitchmix_n`은 완전 동일 → **하나만 쓰면 됨**

### Insight E. 연도 drift가 크다 → 시간순 검증이 맞다

- target rate: 2019 약 **0.565** → 2024 약 **0.486** (하락)
- 과거 `success_rate` 평균도 같이 하락
- 구종 비율은 비교적 안정
- 결측률은 전 시즌 매우 낮음

→ random split보다 **2024 holdout** 같은 시간순 검증이 적절

### Insight F. 피처 간 관계

주요 Pearson 상관 (전체 train):

| 관계 | 상관 | 해석 |
| --- | --- | --- |
| `n` ↔ `pitchmix_n` | **1.00** | 완전 중복 |
| `success` ↔ `reverse` | **약 -0.81** | 강한 음의 관계 |
| `ball` ↔ `strike` | 약 -0.77 | 반대 경향, 그래도 합≠1 |
| `success` ↔ target | 약 **+0.08** | 양의 관계, 숫자는 작음 |
| `reverse` ↔ target | 약 **-0.08** | 음의 관계, 숫자는 작음 |

산점도 해석:

- ball vs strike: 음의 구름 (완벽한 `y=1-x`는 아님)
- fastball vs breaking: 대각선 위가 비어 있음 → 합≤1 제약
- success vs strike: 뚜렷한 직선 관계 약함

## 5. Target 관계 (분위수 구간)

![image.png](4%EB%B2%88%20EDA%20-%20%ED%97%88%EC%B0%AC/image%205.png)

### 무엇을 했나

- 각 rate를 10분위로 나눔
- 구간마다 **실제 target 성공률** + 95% 근사 오차막대
- 연도 내부 상관도 따로 계산 (drift 보정 관점)

### 그림 읽는 법

- x축: 그 분위 구간의 **피처 평균값** (분위 번호가 아님)
- y축: 그 구간의 **실제 제구 성공률**

### Insight G. 담당 피처 중 target과 제일 분명한 축

| 피처 | 패턴 |
| --- | --- |
| `success_rate` | 높을수록 target↑ (낮은 구간~높은 구간이 대략 0.46↔0.61로 갈라짐) |
| `reverse_rate` | 높을수록 target↓ |
| `middle_rate` / `ball_rate` | 대체로 ↓ 쪽 |
| strike / 구종 | 변화 작거나 들쭉날쭉 |

### “피어슨은 작은데 그림은 선명해 보이는” 이유

- target이 **0/1**이라 점 하나하나와 직선 상관은 작아지기 쉬움
- 분위 그림은 **그룹 평균**이라 노이즈가 상쇄되어 차이가 잘 보임
- 따라서:
    - 절대적 Pearson: **낮은 편**
    - 담당 피처 안 순위 / 구간별 차이: **success·reverse가 가장 중요**

> 평균적으로 누적 제구 성공률이 높을수록, 누적 의도반대 비율이 낮을수록 이번 투구의 제구 성공 확률이 더 높다.
> 
> 
> 다만 피어슨 숫자만 보면 약해 보이므로, 구간별 성공률로 확인하는 게 맞다.

## 결론

1. **결측 792건 = cold-start** → `n`과 함께 처리
2. `n`**과** `pitchmix_n`**은 동일 컬럼** → 하나면 충분
3. **ball+strike ≠ 1** → 하나를 `1-나머지`로 대체 금지
4. **구종 3개는 합≈1** → composition으로 이해
5. **연도 drift 큼** → 시간순 validation 유지
6. **target과 제일 분명한 신호는 success↑ / reverse↓**
7. 이 결과는 **담당 10개만의 EDA**이며, 전체 모델 성능과 동일하지 않음
