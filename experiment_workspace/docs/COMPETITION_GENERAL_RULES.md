# LG Aimers 9기 온라인 해커톤 일반 대회 규칙

## 1. 개인·팀 참여

- 개인 또는 팀으로 참가할 수 있다.
- 개인 참가자는 별도 팀 신청 없이 제출 탭에서 제출할 수 있다.
- 팀 참가와 팀 병합은 대회 팀 탭의 최신 정책을 따른다.
- 팀 구성 방법은 팀 페이지의 안내를 따른다.
- 팀 최대 인원은 5명이다.
- 동일인이 개인과 팀에 동시에 등록하거나 여러 팀에 중복 등록할 수 없다.

## 2. 모델·데이터·추론 규칙

### 2.1 사전학습 모델과 가중치

다음 조건을 모두 만족하는 모델과 가중치만 사용할 수 있다.

- 누구나 공식적으로 가중치를 내려받을 수 있음
- 최소한 비상업적 이용이 허용된 라이선스로 배포됨
- 예: MIT, Apache 2.0 또는 이에 준하는 허용 라이선스
- 제출 환경에서 로컬로 실행하고 재현할 수 있음

조건을 만족하지 않거나 라이선스를 확인할 수 없는 모델·가중치는 사용하지
않는다. 사용 시 모델명, 버전, 다운로드 출처, 라이선스를 별도 기록한다.

### 2.2 외부 API

- OpenAI API, Gemini API처럼 원격 서버에서만 접근 가능한 모델은 사용할 수
  없다.
- 모델 학습과 추론은 로컬 코드로 직접 실행하고 재현할 수 있어야 한다.
- 외부 서버 응답에 의존하는 피처 생성·학습·추론은 금지한다.

생성 AI를 코드 작성 보조 도구로 사용하는 것과 제출 모델이 외부 API에
의존하는 것은 구분한다. 최종 학습·추론 파이프라인은 외부 API 없이 완전히
재현돼야 한다.

### 2.3 외부 데이터

- Phase 2에서 주최 측이 제공한 공식 데이터만 사용할 수 있다.
- 별도 수집한 경기 기록, 선수 정보, 통계, 크롤링 데이터는 사용할 수 없다.
- Trackman 보조 데이터도 대회에서 공식 제공한 파일만 사용할 수 있다.
- 공개 데이터라도 대회에서 제공하지 않았다면 사용하지 않는다.

### 2.4 평가 데이터 행 독립성

평가 데이터의 각 행은 독립적인 예측 대상이다. 한 행의 예측에는 다음 정보만
사용할 수 있다.

- 해당 평가 행 자체의 입력 변수
- 주최 측 공식 학습 데이터
- 공식 학습 데이터만으로 만든 통계·모델·파생변수

다른 평가 행 또는 평가 데이터 전체 분포를 사용해 특정 행의 예측을 만들거나
보정하면 안 된다. 구체적인 금지 패턴과 테스트 방법은
[`COMPETITION_RULES.md`](COMPETITION_RULES.md)를 따른다.

## 3. 종료 후 코드·PPT 제출

Phase 3 진출 희망 팀은 대회 종료 후 운영진이 지정한 기한과 양식에 맞춰
`dacon@dacon.io`로 자료를 제출한다.

Private 리더보드 상위권이더라도 자동으로 진출하는 것은 아니다. 코드와 PPT를
제출하고 검증까지 통과한 상위 약 100명이 Phase 3 진출 대상이 된다.

### 코드 형식

- 허용 확장자: `.py`, `.ipynb`
- 코드와 주석 인코딩: UTF-8

### 필수 제출 자료

- [ ] 학습 코드 개발 환경의 OS와 라이브러리 버전
- [ ] Private Score 재현용 전체 학습 코드
- [ ] 리더보드에 제출한 최종 추론 코드
- [ ] 자유 형식 솔루션 PPT
- [ ] 모든 팀원의 Phase 3 참가 여부

학습 코드에는 데이터 로드부터 피처 생성, 모델 학습, 가중치 저장까지 Private
Score를 재현하는 데 필요한 과정이 빠짐없이 포함돼야 한다.

## 4. 운영상 유의사항

- 하루 최대 제출 횟수: 5회
- 사용 가능 언어: Python
- 대회 직후 공개되는 Private 순위는 코드 검증 전 임시 결과임
- 최종 Phase 3 진출자는 코드·PPT 검증 후 결정됨
- 의도적인 평가 데이터 유출 등 코드 제출 기능 악용은 실격 사유임
- 시스템 부하와 스케줄링에 따라 같은 제출물도 추론 시간이 달라질 수 있음
- 평가 서버에서 실제 측정한 리더보드 점수만 공식 결과로 인정됨
- 부정 제출 이력이 있으면 평가가 제한될 수 있음
- 부정행위 규정: [데이콘 부정 제출 관련 공지](https://dacon.io/notice/notice/13)

## 5. 질문 및 공식 답변

- 운영진은 주로 대회 운영과 데이터 이상 관련 질문에 답변한다.
- 일반적인 아이디어·모델링 질문은 토론 페이지에서 참가자끼리 논의한다.
- 데이콘의 공식 답변이 필요하면 토크 게시글 댓글에 답변 요청임을 명시한다.

예시:

```text
[DACON 답변 요청] 질문 내용
```

규칙이 모호하면 임의로 유리하게 해석하지 않고 공식 답변을 받은 뒤 실험 또는
제출에 반영한다.

## 6. 실험 시작 전 체크리스트

- [ ] 사용 데이터가 모두 대회 공식 제공 파일인가?
- [ ] 외부 통계·크롤링·별도 선수 정보가 없는가?
- [ ] 사전학습 모델의 공개 여부와 라이선스를 기록했는가?
- [ ] 학습과 추론이 외부 API 없이 로컬에서 재현되는가?
- [ ] 평가 행 독립성 테스트를 통과하는가?
- [ ] Python 코드와 주석이 UTF-8인가?
- [ ] OS·Python·라이브러리 버전을 기록했는가?
- [ ] 전체 학습 및 추론 과정을 재현할 수 있는가?
- [ ] 팀 구성과 중복 등록 규칙을 준수하는가?

하나라도 확실하지 않으면 해당 실험이나 제출을 보류하고 데이콘에 문의한다.
